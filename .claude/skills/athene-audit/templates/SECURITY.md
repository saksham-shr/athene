# Security policy

## Reporting a vulnerability

Report security issues privately — not in a public issue or PR. Use one of:
<!-- Replace with a real private channel: GitHub private vulnerability reporting

- GitHub private vulnerability reporting (Security tab → Report a vulnerability)

Include: what you found, how to reproduce it, and the potential impact. Expect an initial
response within a few business days.

## Disclosure

Reporters get credit in the fix's release notes unless they ask not to. Fixes are disclosed
publicly only after a patch is available.
