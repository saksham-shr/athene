# Support

## Getting help

Use the [GitHub issue tracker](https://github.com/saksham-shr/athene/issues) for bug reports,
feature requests, installation help, and documentation corrections. Include the agent you are
using, its version, the skill invoked, and a minimal reproduction where possible.

Community discussion is available in the [Athene Discord](https://discord.gg/CT6wsqa2Ct).

## Security and privacy concerns

Do not publish credentials, private repository contents, or other sensitive data in a public
issue. Open a private GitHub security advisory for security vulnerabilities. For privacy concerns
that cannot be shared publicly, contact the maintainer through the GitHub profile listed in the
repository metadata.

## Scope of support

Athene maintains its skill instructions and package metadata. Support for an agent host, GitHub,
or another connected service is provided by that service's maintainers.
